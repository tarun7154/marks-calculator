# Marks Calculator - Student Grade Management System

A modular Python application developed for student grade processing, report card generation, and academic performance analysis as part of the VITyarthi project coursework.

## Features
* Interactive console menu system (`main.ipynb`)
* Automated grade assignment based on percentage thresholds
* Class analytics: Topper identification and class average calculation
* Data persistence via local file I/O (`data/marks.txt`)
* Unit testing suite for core calculation functions

## Technologies Used
* **Language:** Python 3
* **Environment:** Jupyter Notebook (`ipynb`) / Python CLI
* **Testing:** Standard assertions / pytest

## File Structure
* `main.ipynb` - Primary driver menu notebook
* `marks.py` - Student record addition, display, and file I/O
* `grades.py` - Grade calculation logic, total, and percentage computation
* `report.py` - Report card display, topper identification, and class average
* `test project.py` - Automated unit tests for calculation modules
* `data/` - Folder containing persistent student records (`marks.txt`)
